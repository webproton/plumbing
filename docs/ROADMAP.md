# ROADMAP — подготовка к Production

Декомпозиция работ по итогам аудита (октябрь 2026).
Статусы: `[x]` сделано · `[~]` в работе · `[ ]` не начато.
Каждый пункт — отдельный коммит (или серия) в ветке `refactor/production-readiness`.

Принятые решения:
- резерв товара — **при создании заказа**, списание — при завершении, освобождение — при отмене;
- остатки и количества — `Decimal(12,3)` (трубы/шланги продаются метрами);
- все API — под префиксом `/api/`;
- мусор и ошибочная логика удаляются отдельными коммитами;
- фронтенд переписывается на TypeScript (Vite, React 19, React Router 7, TanStack Query) с новым UX.
