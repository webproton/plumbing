# ROADMAP — подготовка к Production

Декомпозиция работ по итогам аудита (октябрь 2026).
Статусы: `[x]` сделано · `[~]` в работе · `[ ]` не начато.
Каждый пункт — отдельный коммит (или серия) в ветке `refactor/production-readiness`.

Принятые решения:
- резерв товара — **при создании заказа**, списание — при завершении, освобождение — при отмене;
- остатки и количества — `Decimal(12,3)` (трубы/шланги продаются метрами);
- все API — под префиксом `/api/`;
- мусор и ошибочная логика удаляются отдельными коммитами;
- фронтенд переписывается на TypeScript (Vite, React 19, React Router 7, TanStack Query) с новым UX.

# Этап 2 — развитие (решения от 2026-10-17)

Решения: интерфейс **українська (по умолчанию) + русский**; B2B-источники — общая структура коннекторов
(фид/файл, API, сайт с логином), конкретных поставщиков подключаем по мере получения доступов; ИИ (Claude API) —
запасной вариант разбора накладных; онлайн-оплата — модуль провайдеров с включением/выключением, сейчас только
ручная оплата по счёту.

проверяем арифметику (кол-во × цена = сумма, сумма строк = итог). Существующий парсер остаётся первым.
- [x] Эталон и защита от регрессий: `python -m parsers.regress snapshot|compare|record`, 10 обезличенных кейсов (2026-10-19)
- [x] Латинская «i» вместо «і» в шапках 1С (цена/сумма брались из кодов товаров); Santan: штрихкод попадал в артикул
- [x] Проверка разбора (арифметика) и показ в кабинете
- [x] Разбор по содержимому колонок, если основной парсер не сошёлся (переставленные/неверные/отсутствующие заголовки)
- [x] Ручные колонки на накладную + «запомнить для поставщика» (несколько профилей, применяется совпавший по шапке)
- [x] PDF (текстовые, таблицы с линиями и без); сканы/фото — через ИИ
- [x] ИИ-разбор (Claude) как запасной вариант: `INVOICE_AI_MODE=off|manual|auto`, в фоне; по умолчанию выключен
- [x] Сопоставление товаров устойчиво к «двойникам» букв (латинская i в названиях, кириллические С/Т/Н в артикулах)
